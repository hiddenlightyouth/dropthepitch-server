첨부한 문서를 읽고 브리프를 작성하세요.

- 근거 위치는 PDF면 'p.N'(파일의 N번째 페이지, 인쇄된 쪽번호가 아님)으로 씁니다. 마크다운·텍스트처럼 페이지가 없으면 헤딩 경로('## 지원 내용 > ### 지원 기간')로, 헤딩이 없으면 'N번째 문단'으로 씁니다. 표는 '표: 첫 행 내용'으로 씁니다. 페이지가 없는 자료에 페이지 번호를 만들어 쓰지 않습니다.
- 표, 그래프, 이미지 안의 숫자와 문구도 본문과 동일하게 다룹니다. 그래프에서 값을 읽어야 하면 읽은 값을 쓰고 uncertainties에 '판독 불확실: '로 남깁니다.
- 문서에 여러 안이나 여러 페이지가 있어도 하나의 브리프로 통합합니다.
- timeline은 빈 배열로 둡니다.
